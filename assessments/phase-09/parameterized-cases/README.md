# Phase 09 parameterized validation cases

Unseen inputs for the computational problems, so answers cannot be copied. Each case is a JSON file `{"lesson": "P09.NN", "seed": int, "inputs": {...}, "expected": {...}, "tolerance": {...}}`, named `p09-NN-<family>-<seed>.json`. Generate new ones with `generate.py` (which uses the reference solutions in `solutions/phase-09/`) and check a learner's implementation with `run.py`, which imports the learner's `starter/main.py` through the same `load_impl` mechanism as the lesson tests. **Seed convention:** the published example cases use seed = 1000 × lesson number + case index (so `p09-16-lqr-16003.json` is the third LQR example); a reviewer generates fresh cases from a seed drawn at review time (`secrets.randbelow(2**31)`), writes the seed into the review record, and anyone can regenerate the identical case from it. Everything random inside a case (polynomial coefficients, pole and zero locations, weights, sample rates, noise added to a synthetic record, Monte Carlo draws) comes from `numpy.random.default_rng(seed)` in a fixed order documented in `generate.py`, so a case depends on its seed and on nothing else. Expected values come from a closed form wherever the theory has one, and otherwise from an independent oracle: the SciPy routines that the lessons use only in their tests (`scipy.signal.lti`, `step`, `bode`, `freqs`, `freqz`, `lfilter`, `butter`, `cont2discrete`, `place_poles`, `dlti`, `dimpulse`; `scipy.linalg.expm`, `solve_continuous_are`, `solve_discrete_are`, `solve_continuous_lyapunov`), `numpy.roots` and `numpy.linalg.eigvals` of an independently assembled closed-loop matrix, and `scipy.integrate.solve_ivp` at tight tolerances for nonlinear simulation. Every case also contains a *limit* or an *identity* that its theory must reproduce exactly (a zero input, K → 0 or K → ∞, ζ = 1, a pure delay, S + T = 1, an ARE or Lyapunov residual, the angle condition, z = e^{sT} for the poles), so an implementation that returns the right number at the generated point by tuning cannot pass. Tolerances are set so that a correct from-scratch implementation passes and a specific, named error fails; each bullet states both, with the size of the error taken from a probe run on the exam's own numbers (`assessments/phase-09/exam.md`). No case contains a measurement; inputs that imitate one (a gyro record, a servo step test) are labelled `"synthetic": true` in the JSON, and `run.py` prints that label with the result.

Cases planned, one family per computational lesson:

- `p09-01-properties-*.json` (P09.01): a discrete-time operator assembled from the seed out of 1–4 blocks (delays, constant and time-varying gains, a saturation with a seeded limit, an affine bias, an accumulator, a first-order recursion with |a| < 1 or |a| ≥ 1, a centred smoother, a decimator), the record length and the test amplitude → the five verdicts (linear, time-invariant, causal, memoryless, BIBO stable) and, for LTI blocks, the impulse response and Σ|h|. **Oracle:** the analytic verdict of each block and the composition rules (a series connection is causal if every block is, linear if every block is), applied by separate code; Σ|h| in closed form for the recursions. **Limit:** a linear block maps zero to zero exactly; the impulse response of y[n] = a y[n − 1] + b x[n] is b aⁿ to 10⁻¹². **Tolerance:** the verdicts must match exactly; every case's record is at least ten time constants of its slowest recursion and its amplitude spans at least twice any saturation limit, so a correct falsification tester decides correctly, while a linearity test run only below the saturation limit, or a stability test that ignores the record length, fails the cases built to catch it.
- `p09-02-convolution-*.json` (P09.02): two seeded sequences of lengths 1–4000, and seeded exponential, rectangular and first-order continuous signals with a grid step → the linear convolution by the direct sum and by the FFT, and the Riemann-sum continuous convolution. **Oracle:** `numpy.convolve` for the discrete case; the closed forms e^{−at} ∗ e^{−bt} and rect ∗ rect for the continuous case. **Limit:** convolution with δ[n] returns the input; the output area equals the product of the areas. **Tolerance:** discrete results atol 10⁻¹⁰ Σ|x| max|h|, so an FFT product without zero padding (in the exam's question 5(c) it corrupts the first two samples by −0.3 and −0.2) fails; the continuous results are checked on two grids a factor of two apart, and the error ratio must be 2 ± 0.1 for the rectangle rule and 4 ± 0.2 for the trapezoid rule (the exam's question 5(b) rectangle sum at dt = 1 μs is 1.0 × 10⁻³ high at 1 ms, of the order of dt/τ), so a rule that is not the one claimed fails the order check.
- `p09-03-block-diagram-*.json` (P09.03): 2–6 blocks of order ≤ 3 with seeded coefficients, connected in series, parallel and negative or positive feedback by a seeded wiring → the reduced transfer function, its poles, zeros and DC gain. **Oracle:** an independent state-space interconnection of the same wiring, its transfer function evaluated as C(sI − A)⁻¹B + D at 20 seeded complex points, and the step of the unreduced interconnection simulated by `scipy.signal.lsim`. **Limit:** a unity loop around a type-1 forward path has DC gain 1; a loop with zero gain returns the forward path. **Tolerance:** the frequency responses agree to rtol 10⁻⁹ (coefficients are not compared, since they are defined only up to a common factor), so a feedback sign error fails at once (it turns the exam's pitch loop of question 6 into s⁴ + 25s³ + 185s² − 178s − 900, unstable).
- `p09-04-step-metrics-*.json` (P09.04): ζ ∈ [0.1, 0.95] and ω_n from the seed, optionally a third pole or a zero at a seeded multiple of ζω_n, a sample time → rise (10–90 %), peak time, overshoot, settling (±2 %) from the sampled response and from the formulas, and the partial-fraction step response. **Oracle:** the closed-form second-order step and its exact metrics (rise and settling by bisection on the closed form); `scipy.signal.step` and `scipy.signal.residue`. **Limit:** ζ = 1 has no overshoot; a zero at infinity reproduces the plain second-order system. **Tolerance:** overshoot atol 10⁻³ points and times atol one hundredth of a sample on a grid of at most T_p/1000, so the wrong conventions fail: on the exam's 5 % servo (question 7) the 0–100 % rise time is 0.178 s against 0.116 s for 10–90 %, and the ±5 % settling time is 0.158 s against 0.331 s for ±2 %.
- `p09-05-bode-*.json` (P09.05): a seeded rational transfer function with 0–2 integrators, real and complex poles and zeros (some in the right half plane) and an optional delay, and a frequency grid → magnitude in dB, unwrapped phase, the asymptotic Bode lines, the crossover and the closed-loop bandwidth. **Oracle:** `scipy.signal.freqs` and `bode`; the phase as the sum of factor angles computed separately; a simulated sine response fitted at three seeded frequencies. **Limit:** low-frequency slope −20 dB/decade per integrator and phase −90° each; the asymptote error at a real corner is exactly 3.01 dB. **Tolerance:** magnitude atol 10⁻⁹ dB, phase atol 10⁻⁷ degrees after unwrapping from the low-frequency value, so a phase left wrapped into (−180°, 180°] fails (on the exam's servo of question 13 at 100 rad/s it reports +155.4° instead of −204.6°).
- `p09-06-sampling-butterworth-*.json` (P09.06): a sample rate, tone frequencies above and below Nyquist, a passband edge with an allowed loss, a vibration line with an allowed alias amplitude, and a seeded synthetic gyro record (`"synthetic": true`) → the alias frequencies, the minimum Butterworth order and the allowed corner range, the analog prototype, its DC group delay and the residual alias in the sampled record. **Oracle:** the folding rule in closed form; `scipy.signal.butter(analog=True)`; the FFT of the sampled, filtered record (filtered by `lsim` on a fine grid). **Limit:** a tone exactly at f_s aliases to 0 Hz; the Butterworth magnitude at the corner is −3.0103 dB for every order. **Tolerance:** alias frequencies exact; the order exact; prototype coefficients rtol 10⁻¹⁰; residual alias amplitude within 2 % of the prediction (the generator makes the record a whole number of alias periods, so the alias falls exactly on an FFT bin, and keeps the added noise's contribution in that bin below 0.5 % of the alias amplitude); so |f − f_s| used instead of folding (520 Hz instead of 20 Hz for the 1020 Hz line of question 9) and an order rounded down (order 2 leaves an empty corner range there) fail.
- `p09-07-digital-filters-*.json` (P09.07): a sample rate and a seeded specification (moving-average length, FIR length and window, IIR order and corner, with or without prewarping) and a seeded synthetic gyro record (`"synthetic": true`) → the coefficients, the frequency response at seeded frequencies, the impulse response from the difference equation, the group delay and the filtered record. **Oracle:** `scipy.signal.freqz`, `lfilter`, `butter` (digital); the moving average's closed-form Dirichlet kernel. **Limit:** a prewarped bilinear filter is exactly −3.0103 dB at its corner; a symmetric FIR has constant group delay (N − 1)/2. **Tolerance:** responses rtol 10⁻⁹, so a missing prewarp fails (the exam's question 10 filter is −3.023 dB at 30 Hz without it, a corner at 29.91 Hz); stability verdicts exact (every pole strictly inside the unit circle).
- `p09-08-steady-state-*.json` (P09.08): a seeded plant of type 0–2, a controller (P, PI, PD, PID), command types (step, ramp, parabola) and disturbance injection points (plant input or output) → system type, error constants, steady-state errors to each command and each disturbance, and S and T at seeded frequencies. **Oracle:** the final-value theorem applied by independent code after a stability check by `numpy.roots`; a long simulation by `scipy.signal.lsim` with the input interpolated linearly, so a held ramp does not add a half-step lag. **Limit:** S + T = 1 to 10⁻¹² at every frequency; an unstable loop must be reported as such and given no steady-state error. **Tolerance:** errors rtol 10⁻⁹ against the closed form, so taking the plant's type as the loop's type for an input disturbance (zero instead of d/K_p = 3.33 × 10⁻⁴ rad for the satellite of question 11) fails, and so does applying the final-value theorem to an unstable loop.
- `p09-09-root-locus-*.json` (P09.09): a seeded G with 2–5 poles and 0–2 zeros (some complex) and a damping target → real-axis segments, asymptote angles and centroid, breakaway points, jω crossings with their gains, and the gain for the target ζ. **Oracle:** the closed-loop roots from `numpy.linalg.eigvals` of the companion matrix of the characteristic polynomial; the Routh array built by separate code; the angle condition ∠G = 180° checked at every returned point. **Limit:** at K → 0 the roots are the open-loop poles, at K → ∞ they tend to the zeros and the asymptotes. **Tolerance:** angle residual below 10⁻⁶ degrees at every returned point, gains rtol 10⁻⁸, so a centroid that omits the zeros (−1.167 instead of −0.75 for the T_d = 0.5 design of question 12) and a breakaway reported where K < 0 fail.
- `p09-10-nyquist-margins-*.json` (P09.10): a seeded loop with integrators, right-half-plane poles and an optional delay → P, the encirclement count N, Z = N + P, the gain margins (upper and lower), the phase margin and the delay margin. **Oracle:** the number of closed-loop right-half-plane roots from `numpy.roots` of the characteristic polynomial (with a sixth-order Padé approximant for a delay, checked stable to the same verdict at orders 4 and 8); `scipy.signal.bode` at the crossovers found. **Limit:** a pure gain change by the gain margin puts a closed-loop root on the imaginary axis to 10⁻⁶ of its frequency; adding the delay margin does the same. **Tolerance:** N, P and Z exact; margins rtol 10⁻⁶; so an encirclement counted with the wrong sense (Z = 2 instead of 0 for the airframe of question 13(c)) and a lower gain margin missed (0.5 there) fail.
- `p09-11-pid-*.json` (P09.11): a seeded second- or third-order plant, target poles, a derivative filter time constant, setpoint weights b and c, an actuator limit and a step size → the PID gains, the closed-loop poles and zeros, the step metrics with and without saturation, and with clamping and back-calculation anti-windup. **Oracle:** `numpy.linalg.eigvals` of the closed-loop matrix assembled independently; the linear closed loop against `scipy.signal.step` with no limit active. **Limit:** with the limit never reached, every anti-windup variant equals the linear loop; with K_i = 0 there is no windup. **Tolerance:** poles rtol 10⁻⁹; linear metrics atol 10⁻³ points; saturated metrics atol 0.5 points (the simulation's sample time is part of the case), so the derivative on the error instead of the measurement (18.2 % against 23.9 % for the pitch loop of question 14) and an integrator that keeps integrating while clamped fail.
- `p09-12-lead-lag-*.json` (P09.12): a seeded servo K/(s(τs + 1)) (optionally with a second lag) and targets for crossover, phase margin and K_v → α, T, K_c, β, z and the achieved margins. **Oracle:** the margins measured on the compensated loop by independent code and by `scipy.signal.bode`; K_v from the limit sL(s). **Limit:** with β = 1 the design reduces to the lead alone; a target PM below the plant's needs no lead (α = 1). **Tolerance:** crossover rtol 10⁻⁶, PM atol 10⁻⁴ degrees, K_v rtol 10⁻⁹, so a lead designed without the lag's phase at crossover (PM 50.36° instead of 55° for question 15) fails, and a request for more than 65° of lead from one stage must raise an error rather than return a compensator.
- `p09-13-state-space-*.json` (P09.13): a seeded proper transfer function of order 1–6, or a seeded (A, B, C, D) → the controllable, observable and modal realisations, the transfer function back from each, a similarity-transformed copy, and the step response by the matrix exponential. **Oracle:** C(sI − A)⁻¹B + D evaluated pointwise at 20 seeded points against the polynomial ratio; `scipy.signal.lti` and `step`; `scipy.linalg.expm`. **Limit:** the eigenvalues of every realisation equal the poles; a similarity transform leaves the transfer function unchanged. **Tolerance:** frequency responses rtol 10⁻⁹ (relaxed to 10⁻⁷ for order 6, where companion forms lose digits), so a companion matrix with its coefficients in reversed order or a missing direct term D fails.
- `p09-14-ctrb-obsv-*.json` (P09.14): a seeded (A, B, C) built with planted uncontrollable or unobservable modes (a block-triangular system hidden by a random similarity transform) and seeded satellite wheel and sensor configurations → the ranks, the PBH modes, the Gramians, and the minimum-energy input for a seeded transfer. **Oracle:** the planted structure (known by construction); `scipy.linalg.solve_continuous_lyapunov` for infinite-horizon Gramians and adaptive quadrature for finite ones; the closed form [[T³/3, T²/2], [T²/2, T]]/J² for the double integrator. **Limit:** a diagonal system with a zero row in B loses exactly that mode; the minimum-energy input reaches its target with a residual below 10⁻⁹. **Tolerance:** ranks and PBH modes exact (planted modes are well separated, and every case's smallest non-zero singular value exceeds 10⁻⁶ of the largest); Gramians rtol 10⁻⁸; so a rank taken without a tolerance, and a PBH test on right instead of left eigenvectors, fail.
- `p09-15-placement-observer-*.json` (P09.15): a seeded controllable and observable single-input system, regulator and observer pole sets, and a seeded synthetic noisy measurement (`"synthetic": true`) → K by Ackermann, L by duality, the reference gain, the combined closed-loop poles and the fitted decay rate of the estimation error. **Oracle:** `scipy.signal.place_poles`; `numpy.linalg.eigvals` of the assembled closed loop; the decay rate from the noise-free error simulated by `expm`. **Limit:** the combined poles are the union of the regulator and observer sets (separation); a zero initial error stays zero. **Tolerance:** placed poles rtol 10⁻⁸ (cases are drawn with a controllability matrix condition number below 10⁶), fitted decay rate rtol 10⁻³ on the noise-free error, so an observer gain built from (A, C) instead of (Aᵀ, Cᵀ) fails.
- `p09-16-lqr-*.json` (P09.16): a seeded stabilisable and detectable (A, B, Q, R) of order 2–8, or a satellite axis with Bryson limits → P by the Hamiltonian and by Newton–Kleinman, K, the closed-loop poles, the ARE residual, the cost of a seeded initial state, and the loop's margins. **Oracle:** `scipy.linalg.solve_continuous_are`; the closed form k₁ = √(q₁/r), k₂ = √(q₂/r + 2Jk₁) for the double integrator (for the exam's question 17 satellite, 0.1432 and 3.1505). **Limit:** the stable half of the Hamiltonian's spectrum equals eig(A − BK); |1 + L(jω)| ≥ 1 at every frequency for single-input cases. **Tolerance:** P rtol 10⁻⁸ and ARE residual below 10⁻¹⁰ relative, and eig(A − BK) checked for stability, so an indefinite (non-stabilising) root of the same equation, which can have a residual of 10⁻¹⁵ (lesson 16, part 4), fails.
- `p09-17-discretization-*.json` (P09.17): a seeded (A, B), sample period T and delay τ ∈ [0, T], and a seeded controller transfer function with a prewarp frequency → the ZOH pair, the delayed augmented model, the Tustin and matched pole-zero equivalents, and the discrete closed loop's margins. **Oracle:** `scipy.signal.cont2discrete` (ZOH and bilinear), `scipy.linalg.expm`, and a simulation resolved between samples that never forms the augmented matrices. **Limit:** eig(A_d) = e^{λT}; τ = 0 and τ = T reproduce plain ZOH and a one-sample delay; G₀ + G₁ = B_d. **Tolerance:** matrices rtol 10⁻¹⁰, so forward Euler in place of ZOH (a pole of 0.8 instead of 0.8187 for question 18(a), 2.3 % off) and a delay model that swaps G₀ and G₁ fail.
- `p09-18-hinf-robustness-*.json` (P09.18): a seeded stable transfer function of order 1–6 (including lightly damped resonances), a controller and plant pair, and a multiplicative-uncertainty weight → the H∞ norm, Ms, Mt, the disk-margin bounds, ‖WT‖∞ and the Bode sensitivity integral. **Oracle:** a dense sweep refined by golden-section search, written separately from the bisection, and the closed form 1/(2ζ√(1 − ζ²)) for a second-order resonance; π Σ Re(p_i) for the Bode integral. **Limit:** S + T = 1; the Hamiltonian test is true at 0.99‖G‖ and false at 1.01‖G‖. **Tolerance:** norms rtol 10⁻⁶, so a sweep on a coarse grid without refinement fails on the narrow peaks the generator includes (a ζ = 0.01 resonance at 150 rad/s on a 200-point grid from 1 to 1000 rad/s reads 32.3 instead of 50.0).
- `p09-19-nonlinear-*.json` (P09.19): a seeded third-order plant with a relay (optionally with hysteresis) or a saturating amplifier; a seeded pendulum stand with a torque limit and a linear gain → the describing functions, the predicted limit cycle, the Lyapunov matrix, and the region-of-attraction level. **Oracle:** the first-harmonic gain computed by numerical Fourier integration over one period; the limit cycle from `scipy.integrate.solve_ivp` with event-located switching; `scipy.linalg.solve_continuous_lyapunov`. **Limit:** a saturation driven inside its linear range has N = k exactly; the Lyapunov residual is below 10⁻¹⁰. **Tolerance:** describing functions rtol 10⁻⁸ against the numerical Fourier integral; the predicted limit-cycle amplitude within 10 % and frequency within 7 % of the simulated cycle (the method's own error: 6 % and 4 % for the relay of question 20, 5 % and 4 % for its saturation); the region estimate must be inside the simulated region of attraction at every one of 200 seeded initial states (a convergence check, not an equality).
- `p09-20-mpc-*.json` (P09.20): a seeded stabilisable discrete (A_d, B_d) of order 1–6, weights, a horizon, a terminal weight, box limits on input, input rate and one output, and an initial state → the condensed H and F, the unconstrained first-move gain, the constrained first move, and a closed-loop run. **Oracle:** the backward Riccati recursion and `scipy.linalg.solve_discrete_are` for the gains; the KKT conditions (stationarity, primal and dual feasibility, complementarity) checked by separate code for the constrained move. **Limit:** with the terminal weight from the discrete Riccati equation the gain is independent of the horizon; with no constraint active the constrained move equals −K x₀. **Tolerance:** gains rtol 10⁻⁸; KKT residuals below 10⁻⁸; no constraint violated by more than 10⁻⁹ in the closed-loop run; so a terminal weight Q used where P was specified (the first gain is 76 % away from the infinite-horizon gain at N = 5 on the `P09.20` altitude model, question 21) and a QP that returns an infeasible point fail.
- `p09-21-identification-*.json` (P09.21): a seeded synthetic step test (`"synthetic": true`) of K e^{−Ls}/(τs + 1) or K e^{−Ls}/(s(τs + 1)) with a dead zone, the sample rate, noise level and quantum, and a seeded P or PI design target → the identified K, τ, L, u_dz with standard errors, the designed gain, and the predicted closed-loop metrics. **Oracle:** the generating parameters (known by construction); `scipy.signal.step` for the predicted closed loop. **Limit:** a noiseless, unquantised record returns the generating parameters to 10⁻⁶. **Tolerance:** each identified parameter within four of its own standard errors of the truth (a correct estimator fails one such check with probability 6.3 × 10⁻⁵ when its errors are Gaussian), and the predicted metrics rtol 10⁻⁶ against the oracle for the identified model; so a log-linear fit that uses the whole record instead of the 0.1–0.9 window, and a tail fit that ignores the dead zone, fail.

These are written once the reference solutions for lessons 01–21 are merged (lessons 19 and 20 are being finished); `generate.py` then produces them deterministically from a seed.
