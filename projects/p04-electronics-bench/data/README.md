# Data folder: p04-electronics-bench

- `prediction.md`: every prediction with its uncertainty and the source of each input, dated before any circuit is powered.
- `calibration.csv`: `instrument,quantity,reference_value,reading,unit,spec,date` (meter lead resistance, the reference resistors, the meter's accuracy specifications, the board's supply voltage).
- `raw/YYYY-MM-DD_<tier>_resistors.csv`: `part_id,nominal_ohm,measured_ohm,meter_range,note`.
- `raw/YYYY-MM-DD_<tier>_divider.csv`: `circuit,r_top_nominal_ohm,r_bottom_nominal_ohm,reading,v_in_V,v_out_V,note` (circuit = `8k2_12k` or `1M_1M`).
- `raw/YYYY-MM-DD_<tier>_led.csv`: `r_series_ohm,v_supply_V,v_resistor_V,v_led_V,i_meter_mA,meter_range,note`.
- `raw/YYYY-MM-DD_<tier>_adc_calibration.csv`: `setting,dmm_V,adc_mean,adc_std,n_samples,adc_scale,note` with `adc_scale` = `u16` (MicroPython `read_u16`, 0–65 535) or `n<bits>` (Arduino-style counts, e.g. `n10`).
- `raw/YYYY-MM-DD_<tier>_thermistor.csv`: `ref_temp_C,adc_mean,adc_std,n_samples,adc_scale,r_fixed_measured_ohm,note`.
- `reduced/`: outputs of the analysis script (fits, budgets, `bench_lab.png`).
- `synthetic/`: **SYNTHETIC data**, generated by `make_synthetic_bench_data(seed=2026)` in the lesson code; simulations, not measurements, for learners without the kit and for checking the analysis. Each file's first line says so and every row's `note` column reads `synthetic`.
  - `synthetic_thermistor_sweep.csv`: `ref_temp_C,u16_mean,u16_std,n_samples,r_fixed_nominal_ohm,note`.
  - `synthetic_adc_calibration.csv`: `setting,dmm_V,u16_mean,note`.

Units are in the column names. Never edit a raw file; fix mistakes in the analysis script and say so in the report. A report that uses anything from `synthetic/` says SYNTHETIC in its title, its summary and every figure, and never calls it a measurement.
