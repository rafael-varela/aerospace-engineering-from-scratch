# Data folder: p04-drag-drop

- `prediction.md`: object masses and diameters, air density and its source, k and v_t for both objects, the prediction table of fall times with uncertainties, the expected E_n against the vacuum model at your frame rate, the chosen frame rate and number of drops, the toss range band; written and dated before any drop or toss.
- `calibration.csv`: columns `instrument,reference_value,reading,unit,date` (the frame rate against a stopwatch display; the wall marks against the tape; the scale against a known mass).
- `raw/YYYY-MM-DD_<tier>_drops.csv`: columns `height_m,object,drop,video_file,release_frame,impact_frame,fps_nominal,note`, with `object` = `ball|bag`. One row per drop, in the order performed. A fumbled drop is noted, not deleted.
- `raw/YYYY-MM-DD_<tier>_tosses.csv`: columns `toss,video_file,fps_nominal,release_frame,release_x_m,release_z_m,frame_plus2_x_m,frame_plus2_z_m,apex_frame,apex_x_m,apex_z_m,landing_frame,landing_x_m,spin,note`. Positions are read against the floor and wall marks in metres from the release mark; `spin` is `none|back|top|unknown` with an estimated rate in `note` if visible.
- `reduced/`: outputs of the analysis script: the per-height statistics, the E_n tables, the fit (v_t, u_v, C_D, u_CD, residuals), the toss table, and the plot.

Never edit a raw file. Fix mistakes in the analysis script and say so in the report. Keep the videos; they are your raw data too.

Anything generated by `make_synthetic_drop_data` in the lesson's code is SYNTHETIC and belongs in `reduced/synthetic/` if kept at all, never in `raw/`, and never in a report as data.
