# Data folder: p06-pendulum-sysid

- `prediction.md`: L ± u_L (three readings), g and its source, the predicted f₀ ± u, the predicted frequency at the release amplitude and at half of it with a detectable / not-detectable verdict, the bob's mass and diameter, the predicted b₂ and ζ_eq range, and the predicted amplitude after 120 s. Dated, written before the first swing, never edited afterwards.
- `calibration.csv`: columns `date,item,reference,reading,unit,note`, for example the frame-rate check (`frame_rate,stopwatch 10.00 s,301,frames,30 fps setting`), the three L readings, the bob mass (with pouch), the angle-reading scatter on a still frame, the gyro bias and noise at rest.
- `raw/YYYY-MM-DD_<tier>_run<k>.csv`: one file per run, untouched. Video tiers: columns `t_s,theta_deg` (time from the start of the record, angle from the vertical, positive one way, as read or tracked frame by frame; use the exported frame timestamps). Rate tiers (phone gyroscope, IMU): columns `t_s,omega_deg_s` with the rate about the pivot axis in degrees per second. Comment lines may start with `#`. The lesson's `read_swing_csv` reads either and returns radians (or rad/s).
- `raw/runs.csv`: columns `date,run,tier,file,L_m,release_deg,duration_s,note`, one row per run.
- `reduced/`: outputs of the analysis script (per-run tables, the three plots).

Never edit a raw file. Fix mistakes in the analysis script and say so in the report. Keep the videos and app exports; they are raw data too.

## SYNTHETIC data

`SYNTHETIC_seed619_swing.csv` is **SYNTHETIC**: it was generated by `write_synthetic_csv(path, seed=619, **SYNTH_DEFAULTS)` in the lesson's `solution.py` (the same generator is given in `starter/main.py`; run `python solution.py <out_dir> --write-data` to regenerate it) and is **not a measurement**. Its first lines say so. It imitates a phone-video record of the lesson's pendulum: L = 0.80 m, g = 9.81 m/s², released from rest at 20°, light viscous damping b₁ = 0.003 s⁻¹ plus air drag b₂ = 0.004 rad⁻¹ (no Coulomb friction), integrated with `solve_ivp`; 30 frames per second for 120 s with 2 ms timing jitter (timestamps rounded to 1 ms), angle noise of 0.3° and a protractor offset of 0.5°. Columns `t_s,theta_deg`, 3600 rows. Regenerating it from the seed reproduces the file byte for byte (a test checks the values).

Read it with `read_swing_csv`. To make your own set, call `write_synthetic_csv(<path>, seed=<your seed>)`; keep **SYNTHETIC** in every file name, table caption and plot title derived from it, and never place synthetic files in `raw/`.
