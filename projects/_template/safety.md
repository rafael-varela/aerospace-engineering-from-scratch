# Safety box: <Project title>

Read this before buying anything and again before every session. If any stop criterion is met, stop, make the setup safe, and only then think about what happened.

| | |
|---|---|
| **Hazards** | List each: mechanical (pinch, falling mass, rotating parts), electrical (voltage, battery), thermal, chemical, projectile, eye. |
| **Energy limits** | Maximum mass, drop height, voltage, current, speed, temperature, pressure used in this project. These are the envelope; do not exceed them. |
| **Controls** | Guards, clamps, safety glasses, ventilation, fusing, distance, tethering, standing position. |
| **Supervision** | None needed / adult present / qualified club supervision required. |
| **Location** | Indoors on a stable bench / outdoors clear of people and property / only at a qualified facility. |
| **Regulations** | Any local rules that apply (for example model aircraft rules for outdoor flight). |
| **Stop criteria** | Any unexpected noise, heat, smell, deformation, or motion; any reading outside the envelope; anyone within the exclusion zone. |
| **Disposal** | Batteries, adhesives, broken parts. |
| **Not permitted in this project** | Combustion, propellant, pressure vessels, mains wiring, unguarded rotors, unsupervised outdoor flight. |

Safety is a hard requirement in the rubric: a report without a completed safety box is not graded.
