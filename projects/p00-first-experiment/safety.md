# Safety box: Time a falling object

Read this before buying anything and again before every session. If any stop criterion is met, stop, make the setup safe, and only then think about what happened.

| | |
|---|---|
| **Hazards** | A falling object can hit a foot, a pet, a child, or break something below. Standing on a chair to reach a drop height is a fall hazard for *you*. A hard object can bounce unpredictably. |
| **Energy limits** | Object mass ≤ 0.2 kg. Drop height ≤ 2.0 m. That is at most about 4 J, roughly the energy of a dropped paperback. Nothing heavier, nothing higher, nothing thrown. |
| **Controls** | Soft, non-bouncing object (bean bag, rice-filled sock). Towel or cushion landing pad. Clear a 1 m radius on the floor; nobody and nothing in it during a drop. Release from a position you can reach standing on the floor or on a stable step with a handhold; never from a chair or a ladder's top step. Phone fixed on a stand, not held over the drop zone. |
| **Supervision** | None needed for adults. A child does this with an adult handling the release. |
| **Location** | Indoors, a room with a hard floor and 2 m of clear height, or outdoors on a calm day. |
| **Regulations** | None apply. |
| **Stop criteria** | Anyone or any pet enters the drop zone. The object bounces out of the landing pad toward anything fragile. You feel unsteady reaching the release height. |
| **Disposal** | None. |
| **Not permitted in this project** | Dropping from windows, balconies, or stairwells. Metal or glass objects. Anyone standing under the drop point to "catch" it. |

Safety is a hard requirement in the rubric: a report without a completed safety box is not graded.
