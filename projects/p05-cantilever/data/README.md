# Data folder: p05-cantilever

- `prediction.md`: the strip's measured dimensions with uncertainties, a and L, I and EI, the safe load and the chosen top load, the predicted deflection ± u at each planned load with the budget term by term, the predicted compliance, the predicted profile, and the predicted u(θ₀) with a detectable / not-detectable verdict for a 1 mrad clamp rotation. Dated, written before any load, never edited afterwards.
- `calibration.csv`: columns `date,item,reference,reading,unit,note`, for example each load's mass (`load_400,kitchen scale,402,g,bag + string + hook`), the scale check against a known mass, the repeated unloaded readings that give the reading uncertainty, and the b, h, a and L readings.
- `raw/YYYY-MM-DD_<tier>_loads.csv`: columns `run,mass_g,x_mm,reading_unloaded_mm,reading_loaded_mm,reading_after_mm,photo_unloaded,photo_loaded,note`, one row per load. `reading_after_mm` is the unloaded reading after the load was removed (the permanent-set check). For the dial-gauge tier the readings are gauge readings in mm and the photo columns are empty.
- `raw/YYYY-MM-DD_<tier>_profile.csv`: columns `run,mass_g,x_mm,reading_unloaded_mm,reading_loaded_mm,photo_unloaded,photo_loaded,note`, one row per mark along the strip.
- `reduced/`: outputs of the analysis script (the fit tables and the two plots).

Never edit a raw file. Fix mistakes in the analysis script and say so in the report. Keep the photos; they are raw data too.

## SYNTHETIC data

`synthetic/SYNTHETIC_seed518_loads.csv` and `synthetic/SYNTHETIC_seed518_profile.csv` are **SYNTHETIC**: they were generated by `make_synthetic_cantilever_data(seed=518)` in the lesson's `solution.py` (the same generator is given in `starter/main.py`) and are **not measurements**. The first lines of each file say so. They describe the lesson's strip (25 × 3 mm aluminium nominal, 300 mm free, load at a = 290 mm). The generator's hidden "truth" differs from the nominal inputs on purpose (E = 67.5 GPa, h = 3.01 mm, b = 25.02 mm, a clamp with k_θ = 2000 N·m/rad) and adds normal reading noise of 0.30 mm to every reading.

- `SYNTHETIC_seed518_loads.csv`: columns `mass_g,reading_unloaded_mm,reading_loaded_mm`, loads 0–800 g in 100 g steps, readings at x = a.
- `SYNTHETIC_seed518_profile.csv`: columns `x_mm,reading_unloaded_mm,reading_loaded_mm`, load 700 g, marks at 50, 100, 150, 200, 250, 290 and 300 mm.

Read them with `read_csv` from the lesson code (lines starting with `#` are comments). To make your own set, call `write_synthetic_csv(out_dir, seed=<your seed>)`; keep **SYNTHETIC** in every file name, table caption and plot title derived from it, and never place synthetic files in `raw/`.
