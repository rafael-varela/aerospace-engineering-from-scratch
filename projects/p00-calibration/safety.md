# Safety box: Calibrate a scale and a length measurement

Read this before buying anything and again before every session. If any stop criterion is met, stop, make the setup safe, and only then think about what happened.

| | |
|---|---|
| **Hazards** | Minimal. Small objects (coins) are a choking hazard for young children and pets. Water near electronics. Pinch from calipers. In the enhanced tier: USB-powered electronics only. |
| **Energy limits** | Masses ≤ 2 kg. No heights, no motion, no heating. Voltages ≤ 5 V DC (enhanced tier only). |
| **Controls** | Work on a flat, stable table. Keep water in a closed container away from the scale's electronics and any computer. Keep coins and small parts in a tray. Dry hands before touching electronics. |
| **Supervision** | None needed for adults. A child doing this with an adult is fine. |
| **Location** | Indoors, any table. |
| **Regulations** | None apply. |
| **Stop criteria** | A spill near electronics (unplug first, then clean). Scale displays erratically or will not zero (replace the battery; do not open the case while powered). |
| **Disposal** | Scale battery to battery recycling. |
| **Not permitted in this project** | Nothing high-energy exists in this project. Do not open the scale's case to "adjust" it. |

Safety is a hard requirement in the rubric: a report without a completed safety box is not graded, even for a project this benign. The habit is the point.
