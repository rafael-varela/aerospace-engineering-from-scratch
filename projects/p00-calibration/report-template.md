# Calibrating my instruments: Technical report

**Author:** · **Date:** · **Lesson:** P00.14 · **Equipment tier used:** · **Mode:** physical experiment

## Summary (5 sentences)
Which instruments, how calibrated, the resulting standard uncertainty of a corrected mass and a length measurement, whether the scale's error was offset, scale, or nonlinearity, and the main limitation.

## 1. Objective and requirements
What was to be determined, and the target: an uncertainty statement for each instrument that later projects can use.

## 2. Theory and assumptions
Type A and Type B evaluation, the law of propagation of uncertainty as used, the linear calibration model and its assumptions (no hysteresis, no temperature dependence over the session).

## 3. Prediction (recorded before measurement)
Predicted Type B uncertainties from resolution; predicted readings; predicted error type.

## 4. Apparatus, calibration, and safety
Instruments, reference objects with the source of their official values, room conditions, the completed safety box, deviations from the procedure.

## 5. Results
Raw-data summary; repeatability statistics; calibration fit (a, b, uncertainties); residual plot; placement and hysteresis findings; length results.

## 6. Discussion
Disagreements beyond uncertainty, ranked causes, the follow-up test and what it showed. Does Type A or Type B dominate, and what would reduce the larger one?

## 7. Conclusions and the recipe
The corrected-measurement recipe (reading → corrected value ± U, k = 2) for each instrument, to be reused.

## 8. Reproducibility
Code commit, raw data files, calibration files, BOM tier.
