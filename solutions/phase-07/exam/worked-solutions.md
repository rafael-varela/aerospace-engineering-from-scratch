# Phase 07 Exam: worked solutions and pass thresholds

Attempt the exam first; it has no time limit. Then grade each question against this key and record the result per competency (1 reasoning, 2 analysis, 3 computation, 4 interpretation). **Pass threshold:** proficient (3 of 4) or better on every competency, where "proficient" means the reasoning is right and the result is right to within rounding, even if the presentation is rough. In Part B a correct final number reached by a wrong derivation is *not* proficient: the boundary, the balance and the derivation are what the question tests, and a first-law, entropy or exergy statement quoted without being applied does not count. In Part C the tests must actually pass. In Part D a correct normalised error with the wrong diagnosis drawn from it is not proficient either, and an answer that presents the SYNTHETIC record as if it were a measurement, or a calculation as if it were data, fails the question regardless of its arithmetic. ## Part A

**1.** (a) Blowdown tank: a control volume (boundary inside the tank wall; gas leaves through the orifice; heat may cross the wall); unsteady, because m and U change. Same tank, valve shut, warming: a closed system (heat crosses, no mass); unsteady. Combustor: a control volume (air and fuel in, products out, no shaft work, adiabatic); steady. Sealed ammonia tank: a closed rigid system (heat in, no work); quasi-static warming. The leaving gas carries u plus the flow work pv done on it by the gas behind, so it carries h; the gas still inside is at rest and stores u. Expanding d(mu)/dt = −ṁh + Q̇ gives m cv dT/dt = −ṁ(h − u) + Q̇ = −ṁRT + Q̇: the remaining gas cools by doing that flow work. (b) Two independent intensive properties fix the state of a simple compressible substance. For an ideal gas u and h depend on T alone, so (T, h) is one property counted twice and says nothing about p or v. Inside the dome p = p_sat(T), so (T, p) is again one property. Valid pairs: (p, h) or (T, v) for the gas; (T, v), (T, h) or (p, x) for the mixture. (c) h = u + pv = u + RT; differentiate in T: cp = cv + R. Equipartition: monatomic cp/R = 5/2; diatomic with rotation and frozen vibration 7/2 (γ = 1.4, cp = 1004.7 J/(kg·K) for air); with vibration fully active 9/2. Between 298 and 1250 K the N₂ and O₂ vibrations wake up, adding storage modes, so cp climbs to 1181.7 J/(kg·K). (d) The NASA datum sets h(298.15 K) to the enthalpy of formation; elements are zero, but the air's 0.04 % CO₂ carries 0.0004 × (−393 510) = −157.4 J/mol, i.e. −5.434 kJ/kg. For non-reacting air only differences of h appear and the constant cancels; in a reacting mixture every species is measured from the same elements, so Σn h(T) of reactants and products can be equated directly and the heat of reaction is already inside the numbers (question 14). The lesson 02 balance closes to round-off because U + ∫ṁh dt − ∫Q̇ dt has a zero time derivative identically: a linear invariant, which every Runge–Kutta step preserves exactly. *Proficient:* the four boundaries with steady/unsteady and the h-versus-u reason; the postulate with both counter-examples and valid pairs; cp − cv = R, 5/2, 7/2, 9/2 and the vibration argument; the CO₂ origin of −5.434 kJ/kg, why it cancels and why it is needed for reactions; the linear-invariant argument.

**2.** (a) Kelvin–Planck: no cyclic device converts heat from a single reservoir entirely into work. Clausius: heat does not flow unaided from cold to hot. For a two-reservoir cycle the Clausius inequality reads Q_H/T_H − Q_C/T_C ≤ 0, so Q_C/Q_H ≥ T_C/T_H and η = 1 − Q_C/Q_H ≤ 1 − T_C/T_H. Over a cycle the fluid returns to its state, so the entropy balance gives S_gen = −ΣQ_k/T_k; any claim with S_gen < 0 violates the second law and is rejected (question 8(c)). (b) T ds = du + p dv = dh − v dp. They relate properties only, so they give Δs between two states whatever the path. Throttle: adiabatic, no work, h₂ = h₁, so T₂ = T₁ for an ideal gas; ds = −R dp/p integrates to s₂ − s₁ = R ln(p₁/p₂), and with no heat crossing all of it is generated. Heat Q across ΔT: S_gen = QΔT/(T_HT_C), linear in ΔT at fixed Q. Two equal bodies at T ± ΔT/2: S_gen ≈ CΔT²/(4T²), quadratic, because the heat exchanged itself shrinks with ΔT. (c) The dead state is equilibrium with the surroundings (T₀, p₀, at rest), where no more work can be had. At p₀, ψ = (h − h₀) − T₀(s − s₀) = ∫_{T₀}^{T} cp(1 − T₀/T′) dT′ > 0 for T on either side of T₀ (the integrand changes sign with dT′). At T₀, h = h₀ and s − s₀ = −R ln(p/p₀), so ψ = RT₀ ln(p/p₀), negative below p₀: work must be spent to push such a stream out into the atmosphere. Energy balance 0 = Σṁ(h + V²/2)_in − Σṁ(h + V²/2)_out + ΣQ̇_k − Ẇ; entropy balance 0 = Σṁs_in − Σṁs_out + ΣQ̇_k/T_k + Ṡ_gen; multiply the second by T₀ and subtract: Ẇ = Σṁψ_in − Σṁψ_out + ΣQ̇_k(1 − T₀/T_k) − T₀Ṡ_gen. The last term is the exergy destroyed. (d) The combustor releases chemical exergy (nearly the heating value) into gas at 1400–1600 K by an unrestrained reaction, mixing and heat transfer across large temperature differences; its energy is conserved but about 30 % of the fuel's exergy is destroyed there (question 12). Compressor: η_II = 1 − T₀s_gen/w and η_s = 1 − (h₃ − h₃ₛ)/w; along the exit isobar h₃ − h₃ₛ = ∫T ds ≥ T₀(s₃ − s₃ₛ) = T₀s_gen because T ≥ T₀ there, so η_II ≥ η_s. *Proficient:* both statements, the Carnot bound from Clausius and the cycle test; the Gibbs relations with the property argument, R ln(p₁/p₂), exponents 1 and 2 with the reason; ψ's two limits and the meaning of a negative value, the Gouy–Stodola derivation; the combustor argument and the ∫T ds ≥ T₀s_gen proof.

**3.** (a) Dalton: each species alone in the whole volume exerts p_i = n_iRT/V, so p_i/p = x_i. Amagat: each alone at the mixture's p occupies V_i = n_iRT/p, so V_i/V = x_i. For ideal gases both follow from non-interacting molecules; real-gas molecules interact, so neither is exact and they differ. Each species expands from p to its partial pressure x_ip, so Δs = −R Σx_i ln x_i ≥ 0 per mole; no heat crosses, so all of it is generated (5.763 J/(mol·K) for a 50/50 mixture). The dry-air flow is constant through humidifiers, coolers and cabins while the water flow is not, so per-kilogram-of-dry-air quantities obey simple balances. With the control volume around cabin and manifold, water leaves only with the outflow, whose flow equals the fresh flow; recirculation is inside the boundary and cancels. (b) φ = f/f_st; LHV and HHV are the enthalpies released per kilogram of fuel burned completely with stoichiometric oxygen from and to 298.15 K, with the product water as vapour (LHV) or liquid (HHV); T_ad is the product temperature at which H_products = H_reactants with no heat or work. Ideal-gas enthalpies do not depend on pressure and complete combustion fixes the products, so T_ad does not either. Lean of φ = 1 spare air dilutes the heat; rich of it oxygen is short and the extra fuel releases nothing and dilutes too. (c) At fixed T and p, dG = Σμ_j dn_j ≤ 0 for any spontaneous change, so equilibrium is the minimum of G = Σn_jμ_j with A n = b. Lagrangian L = G/RT − Σπ_i(Σa_ijn_j − b_i); stationarity gives μ_j/RT = Σa_ijπ_i: π_i is the chemical potential of an atom of element i (in units of RT), and a molecule's is the sum of its atoms'. For any atom-balanced reaction Σν_ja_ij = 0, so Σν_jμ_j = 0; with μ_j = g°_j + RT ln(x_jp/p°) this is Π(x_jp/p°)^ν_j = exp(−ΔG°/RT). H₂O ⇌ H₂ + ½O₂ is endothermic (ΔH° = +251.96 kJ/mol at 3000 K) and increases the moles (Δν = +½): higher T raises K and dissociation; higher p pushes it back (question 15). (d) Dissociation needs high temperature: at a stoichiometric 2700 K a few per cent of the products are CO, H₂, OH, O, and breaking those bonds absorbs 140 K or more; at 1600 K and φ ≈ 0.37 the products are nearly all intact and the gap is 3.9 K (question 15(c)). Equilibrium fails where chemistry is slower than the flow: NO formation in a combustor (equilibrium overstates NO, an upper bound), CO burnout at the combustor exit, and the expanding gas in a rocket nozzle (shifting equilibrium overstates the recombination heat release and the performance relative to frozen flow). *Proficient:* Dalton/Amagat with the real-gas caveat, Δs_mix derived and called generated, the per-dry-air and recirculation arguments; the four definitions with the pressure and peak reasons; G minimum, Lagrange conditions, π as atom potentials, mass action derived, Le Chatelier with both signs; the lean/stoichiometric contrast and one failure with its direction.

**4.** (a) q″ = −k∇T; k in W/(m·K), α in m²/s, kt in W/K. In series the same flux crosses each layer, so temperature drops (resistances L/k) add; side by side the same gradient drives each layer, so conductances kt add. The finite-volume row is an energy balance of its control volume, and the conduction conductances are symmetric with zero row sums, so summed over all nodes they cancel in pairs: the global balance is an algebraic identity of the discretisation. Explicit: T_i^{n+1} = T_i + Fo(T_{i−1} − 2T_i + T_{i+1}); a sawtooth mode is multiplied by 1 − 4Fo each step, which exceeds 1 in magnitude when Fo > ½; the implicit scheme's amplification is 1/(1 + 4Fo sin²) < 1 for every Fo. Correlations are fits to data in a stated range: Gnielinski is valid for 2300 ≤ Re ≤ 5 × 10⁶, and question 21's item 3 shows what using it at Re ≈ 2000 does. (d) F₁₂ = (1/A₁)∫∫cos θ₁ cos θ₂/(πs²) dA₂dA₁; the double integral is symmetric in 1 and 2, so A₁F₁₂ = A₂F₂₁; everything leaving i lands somewhere in an enclosure, so Σ_jF_ij = 1.
```python
import numpy as np
from scipy.linalg import solve_banded


def slab_theta(k, rho_c, L, n, T_i, T_s, dt, n_steps, theta=1.0):
    """1-D slab 0 <= x <= L, n intervals, vertex-centred finite volumes. Node 0 is held at T_s from t = 0+,
    node n is adiabatic (half cell). theta method: 0 explicit, 1/2 Crank-Nicolson, 1 implicit.
    Returns (x, T, E_stored, Q_in): energy stored per unit area since t = 0 and heat in through x = 0,
    both J/m^2, Q_in accumulated from the conductance between nodes 0 and 1 at T^theta."""
    dx = L / n
    x = np.linspace(0.0, L, n + 1)
    G = k / dx
    C = np.full(n, rho_c * dx)            # free nodes 1..n
    C[-1] = rho_c * dx / 2
    m = n
    diag = np.full(m, 2 * G); diag[-1] = G
    off = np.full(m - 1, -G)
    T = np.full(n + 1, float(T_i)); T[0] = T_s
    E0 = float(np.sum(C * T[1:]))
    Q_in = 0.0
    ab = np.zeros((3, m))
    ab[0, 1:] = theta * off; ab[1] = C / dt + theta * diag; ab[2, :-1] = theta * off
    for _ in range(n_steps):
        Tf = T[1:]
        KT = diag * Tf
        KT[:-1] += off * Tf[1:]
        KT[1:] += off * Tf[:-1]
        b = C / dt * Tf - (1 - theta) * KT
        b[0] += G * T_s                   # the fixed node enters at full weight (it is constant)
        Tnew = solve_banded((1, 1), ab, b) if theta > 0 else b * dt / C
        T1_th = theta * Tnew[0] + (1 - theta) * Tf[0]
        Q_in += dt * G * (T_s - T1_th)
        T[1:] = Tnew
    return x, T, float(np.sum(C * T[1:])) - E0, Q_in
```
