## Part A

**1.** (a) *Linear:* S(ax₁ + bx₂) = aS(x₁) + bS(x₂) for all inputs and scalars (so zero in gives zero out). *Time-invariant:* delaying the input by k delays the output by k and changes nothing else. *Causal:* y[n] depends only on x[m] for m ≤ n. *Memoryless:* y[n] depends only on x[n]. *BIBO stable:* every bounded input gives a bounded output. The impulse response and convolution, the transfer function, the Bode plot, the Nyquist criterion, the root locus and a constant-matrix state-space model all assume LTI: superposition is what lets the response to any input be built from the response to an impulse, and time invariance is what makes that impulse response the same whenever the impulse arrives. Applied to a non-LTI block they still return a number, but it describes a different system: a saturating converter's "Bode plot" depends on the test amplitude, a decimator has no transfer function at the input rate, and a time-varying gain has a different impulse response at every instant. (b) A linearity test that drives a saturation with amplitudes below its limit finds it exactly linear; a stability test that runs a slow recursion (a pole at 0.999, a time constant of 1000 samples) on a record of a few hundred samples sees an output still growing and calls it unstable, while a short record can also hide the slow growth of a marginally unstable block. Design the test so that the amplitude spans the full sensor range and beyond (at least the converter's full scale), the record is at least five to ten of the slowest time constants, and the inputs include the worst case for the property (for BIBO of an LTI block, the input sign(h[n − k]) reaches Σ|h|). Passing remains evidence, not proof; a single counterexample is proof. (c) An LTI system is BIBO stable if and only if Σ|h[n]| < ∞ (∫|h| dt < ∞): sufficiency by |y| ≤ Σ|h||x|max, necessity by the input x[n − k] = sign(h[k]). The accumulator's h is a unit step, Σ|h| = ∞: a constant bias, which is a bounded input, gives an output growing linearly (question 5(d): 36° in 30 min). A zero-mean input may stay bounded for a while, but BIBO is about every bounded input. Convolution says the output now is a weighted sum of the inputs at every past instant, the weight for an input k samples old being h[k]: a "weighted memory". The FFT multiplies periodic sequences, so its product is a circular convolution of the length used; padding both sequences to at least N + M − 1 points leaves room for the full linear result so nothing wraps around (question 5(c)). A centred smoother needs x[n + 1], a future sample: in post-processing the whole record exists, in a flight loop it does not, and making it causal by waiting one sample adds a delay that costs phase ωT at every frequency. (d) The saturating converter is not linear (and the integrator is LTI but not BIBO stable, which is allowed for a transfer function). Multiplying transfer functions is still approximately right while the signal stays inside the converter's range, where the saturation is the identity. For large signals the tools of `P09.19` replace the transfer function: the describing function for limit cycles, and Lyapunov analysis or simulation for stability. *Proficient:* the five definitions; the LTI assumption named for each tool with a non-LTI failure; the amplitude and record-length traps and how to design them out; the BIBO theorem with the accumulator, the weighted-memory reading, zero padding and the causality argument; the saturation identified with its small-signal validity and the `P09.19` tools.

**2.** (a) G(s) = ∫₀^∞ h(t)e^{−st} dt = Y(s)/U(s) for zero initial state. Each pole p contributes a mode e^{pt} to the natural response (decaying if Re p < 0, oscillating if Im p ≠ 0); zeros do not create modes but set how strongly each mode is excited and block inputs of the form e^{zt} (a zero at s = 0 blocks a constant). Final-value theorem: lim y(t) = lim_{s→0} sY(s), valid only if sY(s) has every pole in the open left half plane. Counterexample: Y(s) = 1/(s(s − 1)) gives sY(0) = −1, but y(t) = eᵗ − 1 grows without bound. (b) For a stable G, the response to sin ωt is a transient that decays (the system's own modes) plus the particular solution, which is the input times G(jω): amplitude |G(jω)|, phase ∠G(jω). A type-1 servo has a pole at s = 0, so its open-loop "transient" includes a ramp that never decays; it must be measured in closed loop (or with a drift-removal scheme) and G(jω) inferred. Asymptotic rules: a real pole changes the slope by −20 dB/decade at its corner and the phase by −90° spread over two decades; a real zero +20 dB/decade and +90°; at a real corner the straight lines are 3.01 dB and 45° in error (the 45° line passes through the exact value at the corner; the maximum straight-line phase error, near a decade either side, is about 5.7°); a pair with damping ζ has a resonant peak 1/(2ζ√(1 − ζ²)) for ζ < 0.707, the straight lines' error at the corner being −20 log₁₀(2ζ). (c) A signal with no content at or above f_s/2 is determined by its samples (and reconstructed by sinc interpolation). A tone at f appears at |f − k f_s| for the integer k that brings it into [0, f_s/2]. After sampling, the alias *is* a low-frequency signal; nothing in the samples distinguishes it from a real 10 Hz motion, so only a filter acting on the continuous signal, before the sampler, can remove it. The ZOH's response (1 − e^{−jωT})/(jω) = T e^{−jωT/2} sinc(ωT/2) is a delay of T/2 times a gain near 1: phase lag ωT/2 radians. z = e^{sT} maps Re s < 0 inside the unit circle, the imaginary axis onto the circle (periodically, the Nyquist frequency π/T to z = −1). (d) An FIR filter has no feedback, so it is always stable; a symmetric N-tap FIR has exactly linear phase, a pure delay of (N − 1)/2 samples, and needs many taps for a sharp cut-off. An IIR filter reaches the same attenuation with few coefficients and less delay at low frequency, but can be unstable (poles outside the circle) and its phase is not linear. The bilinear transform maps the whole jω axis onto the unit circle, so the analog response at ω_a appears at ω_d = (2/T)arctan(ω_aT/2): compressed toward the Nyquist frequency. Prewarping makes one chosen frequency (a corner or a notch) exact; every other frequency is still warped, and the shape of the response away from that point is not restored. *Proficient:* G as the transform of h with poles as modes, the FVT condition with an unstable counterexample; the sine-steady-state argument and why a type-1 plant cannot be measured open loop, the four Bode rules with numbers; the folding rule, the analog-filter argument, ωT/2, the z-plane map; the FIR/IIR comparison and the warping law with what prewarping fixes.

**3.** (a) S = 1/(1 + L), T = L/(1 + L), S + T = (1 + L)/(1 + L) = 1. The error to a reference or an output disturbance is S times it, and the response to sensor noise is T times it; so S must be small where commands and disturbances live (low frequency) and T small where noise and model error live (high frequency), and at any one frequency they cannot both be small because they add to 1. The type is the number of integrators in L; K_p = lim L, K_v = lim sL, K_a = lim s²L, giving step, ramp and parabola errors 1/(1 + K_p), 1/K_v, 1/K_a. For a disturbance torque d entering at the plant input, θ = G/(1 + CG) d; with C = K_p + K_ds and G = 1/(Js²), θ/d = 1/(Js² + K_ds + K_p), whose DC gain is 1/K_p, not 0. What rejects a constant input disturbance is an integrator *in the controller*, between the error and the injection point; the plant's integrators sit downstream of d and do not help (question 11(b)). (b) A point s is on the locus of 1 + KG = 0 (K > 0) if ∠G(s) = 180° (mod 360°); the gain there is K = 1/|G(s)|. Nyquist: map the D contour (up the jω axis, around the right half plane, indented around imaginary-axis poles so that L stays finite on it) through L; N, the number of clockwise encirclements of −1, satisfies Z = N + P, with P open-loop and Z closed-loop right-half-plane poles. An airframe with P = 1 needs N = −1 (one counterclockwise encirclement) for Z = 0; the Nyquist curve must then reach around −1, so *reducing* the gain shrinks it until it no longer encircles: there is a lower gain limit, a lower gain margin below 1 (question 13(c)). (c) |1 + L| is the distance from L(jω) to −1, and 1/|S| = |1 + L|; its minimum over ω is 1/Ms, so the curve stays outside a disk of radius 1/Ms around −1. A gain k moves real-axis crossings by the factor k; they reach −1 only if k leaves (Ms/(Ms + 1), Ms/(Ms − 1)). At crossover |L| = 1, and the unit circle meets the disk's edge at an angle 2 arcsin(1/(2Ms)) from the negative real axis. Ms = 2: gain between 0.667 and 2 (−3.52 dB to +6.02 dB) and PM ≥ 28.96°, at the same time. For G = G₀(1 + WΔ), ‖Δ‖∞ ≤ 1, 1 + CG = (1 + L₀)(1 + TWΔ), and ‖WT‖∞ < 1 guarantees robust stability for every such plant; it is necessary as well, because a Δ of size ≤ 1 with the right phase can be built where |WT| ≥ 1. A pure gain error is a real, constant Δ, a tiny subset of the complex Δ the test allows, so the test is conservative for it (question 19(c): a factor 2.9). A nominal 65° says nothing about a lightly damped mode or a delay above crossover that the model omits; the true loop can cross −1 there. Bode integral: ∫₀^∞ ln|S(jω)| dω = 0 for a stable loop of relative degree ≥ 2, and π Σ Re p_i with right-half-plane open-loop poles p_i: attenuation in one band is paid for by amplification in another, and an unstable plant pays extra. (d) ΔPM ≈ ω_c(T/2 + τ) in radians: half a sample for the hold plus the computational delay. It fails when ω_cT is no longer small (the hold's sinc gain and the shift of the crossover appear) and when τ > T (the model of one held, delayed update no longer holds). A full sample of delay costs ω_cT; halving the sample rate costs only an extra ω_cT/2: delay is worse than slow sampling (question 18(b): 25 Hz with no delay keeps 55.2°, 50 Hz with a full sample keeps 51.7°). One robustness number: Ms (or the disk margin it implies), because it bounds gain and phase *together* and penalises any close approach of L to −1, which separate gain and phase margins can miss; ‖WT‖∞ is better still if a validated uncertainty weight exists, and the delay margin is the honest single number for latency. *Proficient:* S + T = 1 with the frequency split; type and constants with the input-disturbance argument; angle and magnitude conditions, Z = N + P with the indentation, the unstable plant's encirclement and lower gain margin; the disk derivation with 0.667–2 and 29.0°, the small-gain test with its conservatism and the hidden-mode argument, the Bode integral; the rule with its failure conditions and the delay-versus-rate comparison, and a defended choice of number.

**4.** (a) Any invertible change of coordinates x = Tz gives another realisation (T⁻¹AT, T⁻¹B, CT, D) with the same eigenvalues, the same transfer function C(sI − A)⁻¹B + D and the same input–output behaviour; the states change meaning. Controllable: from any state, some input reaches any other state in finite time; rank [B, AB, …, A^{n−1}B] = n. Observable: the initial state is determined by the output over a finite time; rank [C; CA; …; CA^{n−1}] = n. PBH: (A, B) is uncontrollable iff some left eigenvector w of A has wᵀB = 0 (rank [λI − A, B] < n at that λ); the eigenvalue names the mode that cannot be moved. The Gramian W_c(T) = ∫₀ᵀ e^{At}BBᵀe^{Aᵀt} dt measures how much: the minimum input energy to reach x is xᵀW_c⁻¹x, so a small eigenvalue means a direction that is controllable in principle and very expensive in practice (question 16(c), (d)). (b) Ackermann: K = [0 … 0 1] 𝒞⁻¹ φ(A), φ the desired characteristic polynomial and 𝒞 the controllability matrix. Observer: the error e = x − x̂ obeys ė = (A − LC)e; placing eig(Aᵀ − CᵀLᵀ) is the dual placement problem, so Lᵀ = Ackermann(Aᵀ, Cᵀ, observer poles). Separation: with u = −Kx̂, the closed-loop eigenvalues are eig(A − BK) ∪ eig(A − LC), so regulator and observer can be designed separately. It does not promise robustness: the margins of the combined loop can be far worse than either part's (question 17(d)). Observer poles 2–6 times faster than the regulator's make the estimate converge before it matters; faster still means a larger L, which multiplies the sensor noise into the estimate (and into the actuator), and pushes the loop's bandwidth toward unmodelled dynamics. (c) J = ∫₀^∞ (xᵀQx + uᵀRu) dt with Q ⪰ 0, R ≻ 0; AᵀP + PA − PBR⁻¹BᵀP + Q = 0; K = R⁻¹BᵀP. The stabilising P exists when (A, B) is stabilisable and (A, Q^{1/2}) is detectable. From the return-difference identity (1 + L(−jω))ᵀR(1 + L(jω)) = R + G(−jω)ᵀQG(jω), single-input LQR has |1 + L(jω)| ≥ 1: gain margin [½, ∞) and phase margin ≥ 60° at the plant input. An observer (or a Kalman filter) between the sensors and the gain, and a delay or a flexible mode inside the loop, each remove the guarantee. Bryson's rule: Q_ii = 1/(largest acceptable x_i)², R_jj = 1/(largest acceptable u_j)²: a dimensionally sensible first guess, not a design. (d) At each sample, MPC predicts N steps ahead, minimises the quadratic cost over the N future inputs subject to the constraints, applies only the first, and repeats from the new measured state. With no active constraint the minimiser is linear in x₀, and dynamic programming says the minimiser of the same cost is the finite-horizon LQR policy, whose first gain is the one MPC applies; with the terminal cost P from the discrete Riccati equation the tail beyond N is costed exactly, so the first gain equals the infinite-horizon LQR gain for every N (question 18(d), question 21). Lyapunov: if V > 0 except at 0 and V̇ < 0 along trajectories except at 0, the equilibrium is asymptotically stable; every bounded level set {V < c} on which V̇ < 0 is a region from which convergence is proved. A quadratic V of the linearised loop proves local stability of the nonlinear loop and, with the level-set check, an inner estimate of the region of attraction; it does not prove that a larger region fails (question 20(c): 21.3° proved against 42.8° true). The describing function assumes a single sinusoid at the nonlinearity's input, i.e. a plant that filters out the harmonics (low-pass), and a slowly varying amplitude; it predicts the existence, amplitude and frequency of a limit cycle approximately, not exactly. Feedback linearisation cancels the nonlinearity exactly, so it needs the model (here m, l, b, g) exactly and the actuator to deliver the cancelling torque. *Proficient:* non-uniqueness with what similarity preserves; the definitions, rank tests, PBH with the mode, the Gramian as cost; Ackermann, duality, separation and what it omits, the observer-speed trade; the cost, CARE, gain and existence conditions, the return-difference guarantee with two ways to lose it, Bryson as a first guess; receding horizon, MPC = finite-horizon LQR and the terminal cost; Lyapunov's method with what the quadratic V proves, the describing-function assumptions, the exact-model requirement.

```python
import numpy as np


def prediction_matrices(Ad, Bd, N):
    n, m = Bd.shape
    Sx = np.zeros((N * n, n))
    Su = np.zeros((N * n, N * m))
    Ak = np.eye(n)
    for i in range(N):
        Ak = Ad @ Ak                                   # A^{i+1}
        Sx[i * n:(i + 1) * n, :] = Ak
        for j in range(i + 1):
            Su[i * n:(i + 1) * n, j * m:(j + 1) * m] = np.linalg.matrix_power(Ad, i - j) @ Bd
    return Sx, Su


def mpc_gain(Ad, Bd, Q, R, P_N, N):
    """First-move gain K_mpc (u0 = -K_mpc x0) of unconstrained linear MPC with horizon N.

    J = sum_{k=0}^{N-1} (x_k'Q x_k + u_k'R u_k) + x_N'P_N x_N = 1/2 U'HU + x0'F'U + const,
    H = 2(Su'Qb Su + Rb), F = 2 Su'Qb Sx; U* = -H^{-1} F x0. No Riccati recursion.
    """
    n, m = Bd.shape
    Sx, Su = prediction_matrices(Ad, Bd, N)
    Qb = np.kron(np.eye(N), Q)
    Qb[-n:, -n:] = P_N
    Rb = np.kron(np.eye(N), R)
    H = 2.0 * (Su.T @ Qb @ Su + Rb)
    F = 2.0 * Su.T @ Qb @ Sx
    return np.linalg.solve(H, F)[:m, :]
```
