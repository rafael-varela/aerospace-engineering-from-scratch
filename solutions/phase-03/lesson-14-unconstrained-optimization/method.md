# P03.14  Method outlines

The steps, without final numbers. Read `worked-solutions.md` only after you have an answer of your own.

## 1.
(a) g₀ = Qx₀ = (κ, κ); gᵀg = 2κ²; gᵀQg = κ² + κ³ = κ²(1 + κ); α₀ = 2/(1 + κ); x₁ = (κ, 1) − (2κ/(1 + κ))(1, 1) = ((κ − 1)/(κ + 1))(κ, −1). (b) f(x₁) = ((κ − 1)/(κ + 1))² f(x₀) because f is homogeneous of degree 2 and f(κ, −1) = f(κ, 1); the same step repeats with the sign of x₂ alternating. Iterations for 10⁻¹⁰: k = ln(10⁻¹⁰)/ln(ratio). (c) `steepest_descent(f, g, x0, tol, exact_quadratic=Q)`; ratios of successive f − f*; note that a gradient tolerance of 10⁻¹⁰ corresponds to f ≈ 10⁻²⁰, so the count is larger than (b)'s; `bfgs(..., exact_quadratic=Q)` for the n-step termination and H.

## 2.
(a) ∇f(x_{k+1}) ≈ ∇f(x_k) + ∇²f(x_k)(x_{k+1} − x_k) gives y ≈ Bs with B the Hessian, hence H y = s for H ≈ B⁻¹; n equations for n(n + 1)/2 unknowns of a symmetric matrix. (b) Multiply (3) by y on the right: (I − ρysᵀ)y = y − y(ρsᵀy) = 0, leaving ρs(sᵀy) = s. Symmetry: the form VHVᵀ + ρssᵀ. Positive definiteness: zᵀH₊z = (Vᵀz)ᵀH(Vᵀz) + ρ(sᵀz)²; both terms ≥ 0; if the first is zero then Vᵀz = 0, i.e. z = ρy(sᵀz), so sᵀz ≠ 0 unless z = 0. (c) φ'(α) ≥ c₂φ'(0) > φ'(0) (both negative, c₂ < 1), so φ'(α) − φ'(0) > 0, and yᵀs = α(φ'(α) − φ'(0)). (d) ρ = 1/a; V = I − ρsyᵀ = [[1 − 1, −ρ], [0, 1]] = [[0, −1/a], [0, 1]]; VVᵀ = [[1/a², −1/a], [−1/a, 1]]; add ρssᵀ = [[1/a, 0], [0, 0]]; check H₊y = (1, 0); eigenvalues from trace and determinant; one-variable: H = s/y = 1/a, which is H₊'s (1,1) entry only when the second direction is absent.

## 3.
(a) `g1 = gradient_fd(f, x, 2e-4)`, `g2 = gradient_fd(f, x, 1e-4)`, reference (4g₂ − g₁)/3 (Richardson removes the h² term). Loop h; central with `gradient_fd`, forward by (f(x + he_i) − f(x))/h. Slopes +2 (central), +1 (forward), −1 (both, rounding). (b) Define f_m(z) = f((z₀, z₁/10⁴)); `gradient_fd(f_m, (M, h_m), 1e-6)`; `hessian_fd` on both with h = 10⁻² (metres) and 10⁻³ (scaled); `np.linalg.cond`. (c) `bfgs` on both from (0.70, 8000) and (0.70, 0.8), tol 10⁻⁷, max_iter 500; compare `converged`, `iterations`, `f`. (d) Candidates: a scaled gradient ‖D∇f‖ with D = diag(typical variable sizes); relative decrease |f_k − f_{k−1}| < τ|f_k|; relative step ‖s‖/‖x‖. The first is the honest fix (it is equivalent to rescaling); the others can stop at a plateau that is not a minimum.

## 4.
(a) M* and C_L* from the 600 kN run; h* from p* = 2W/(γM*²SC_L*) and h = 11 000 + (RT/g₀) ln(22 632/p*), i.e. Δh = (RT/g₀) ln(W₀/W); fuel ratio W/W₀. (b) `optimal_cruise(dict(ac, W=...))` and `cruise_breakdown`; fit h* = A − (RT/g₀) ln W, slope from any two rows. (c) `fuel_per_km([0.78, 1.1], ac2)` and `fuel_per_km(x600, ac2)` against the new optimum. (d) `hessian_fd` at the new optimum with h = 10⁻³; Δx_i = √(2 × 0.01 f*/H_ii); convert the altitude half-width from tens of kilometres to metres; compare h* with typical ceilings.

## 5.
(a) Counter wrapper; `steepest_descent(tol=1e-6, max_iter=50000)`, `newton_method(tol=1e-10)`, `bfgs(tol=1e-10)`. (b) `error_sequence(path, (1, 1))`, drop entries ≤ 10⁻¹³, ratios e[1:]/e[:-1], `convergence_order`. Linear: constant ratio < 1; quadratic: ratio ∝ e_k; superlinear: ratio → 0 without a fixed power. At the end both logarithms in the estimator are ratios of numbers near the rounding floor. (c) `np.linalg.inv(rosenbrock_hess([1, 1]))` against `res['H']`; BFGS only needs Hg to be a good direction along the path, and the secant equations constrain H only along the s directions visited. (d) Loop with `np.linalg.solve(rosenbrock_hess(x), -rosenbrock_grad(x))`; record `max(f)` along the path.

## 6.
(a) True: ∇f = 0 to tolerance, H ≻ 0 (strict local minimum), the value and its 1 % window. Not established: global minimality (only the single-basin check of §6 suggests it), feasibility (ceiling, buffet, M_MO, flight levels), model validity (polar, engine deck, wind), robustness to weight changes (cruise-climb law). (b) Hessian: ½H₁₁(0.80 − M*)²/f*; direct: `fuel_per_km([0.80, h*])/f* − 1`, and optionally the best altitude for M = 0.80 by a 1-D search; quote the direct one and say why (the quadratic model omits the quartic wave-drag growth). (c) Replace ε by the noise level δ in the rounding term: error ≈ δ|f|/h against truncation C h²; the best h moves to (δ|f|/2C)^{1/3}, of order 10⁻¹ in these variables, i.e. a difference step comparable to the whole design range; gradient errors then exceed gradient changes over BFGS steps, so yᵀs can be negative and updates must be skipped; Nelder–Mead or a smoothing surrogate is the practical answer. (d) min fuel per km over (M, h) subject to h ≤ h_ceiling(W), M ≤ M_MO, C_L ≤ C_L,buffet(M), possibly h in a discrete set of flight levels; `scipy.optimize.minimize(method='SLSQP')` or `'trust-constr'` (or `'L-BFGS-B'` for bounds alone); check which constraints are active, the Lagrange multipliers' signs and that the reduced gradient is zero.
