## Part A

**1.** With x₁ = θ, x₂ = θ̇: ẋ₁ = x₂, ẋ₂ = −(g/ℓ) sin x₁. Jacobian J = [[0, 1], [−(g/ℓ) cos x₁, 0]]. At θ = 0: J = [[0, 1], [−g/ℓ, 0]], tr = 0, det = g/ℓ > 0, eigenvalues ±i√(g/ℓ): a linear centre. At θ = π: J = [[0, 1], [g/ℓ, 0]], det = −g/ℓ < 0, eigenvalues ±√(g/ℓ): a saddle. The Hartman–Grobman (linearisation) theorem says the nonlinear flow near a *hyperbolic* equilibrium (no eigenvalue on the imaginary axis) looks like its linearisation, so the saddle conclusion at θ = π is justified: the inverted pendulum is unstable. A centre is not hyperbolic, so linearisation at θ = 0 proves nothing about the nonlinear system: the undamped pendulum does orbit forever (energy conservation shows it, not the linearisation), but the second sentence is wrong for a different reason: "a little bearing friction" changes the equation. With damping, ẍ₂ picks up −c x₂/(mℓ²): the trace becomes −c/(mℓ²) < 0 while det is unchanged. At θ = 0, tr < 0 and det > 0 give a stable spiral (or stable node if tr² > 4 det), hyperbolic, so now linearisation *does* prove asymptotic stability. At θ = π, det < 0 is still a saddle: damping does not rescue the inverted position. *Proficient:* the two Jacobians, saddle justified and centre not, the hyperbolicity hypothesis named, and the trace–determinant effect of damping at both equilibria.

```python
import numpy as np
import pytest

M0, M_DRY, MDOT, VE, G = 250.0, 100.0, 7.5, 2200.0, 9.81


def rk4_step(f, t: float, y: np.ndarray, h: float) -> np.ndarray:
    """One classical fourth-order Runge-Kutta step for y' = f(t, y)."""
    k1 = f(t, y)
    k2 = f(t + 0.5 * h, y + 0.5 * h * k1)
    k3 = f(t + 0.5 * h, y + 0.5 * h * k2)
    k4 = f(t + h, y + h * k3)
    return y + (h / 6.0) * (k1 + 2.0 * k2 + 2.0 * k3 + k4)


def integrate(f, t0: float, y0: np.ndarray, t_end: float, n_steps: int) -> np.ndarray:
    """Advance from t0 to t_end in n_steps equal RK4 steps; return the final state."""
    h = (t_end - t0) / n_steps
    t, y = t0, np.asarray(y0, dtype=float)
    for _ in range(n_steps):
        y = rk4_step(f, t, y, h)
        t += h
    return y


def vacuum_burn(t: float, y: np.ndarray, mdot: float = MDOT) -> np.ndarray:
    return np.array([mdot * VE / (M0 - mdot * t) - G])


T_B = (M0 - M_DRY) / MDOT                       # 20 s
V_B = VE * np.log(M0 / M_DRY) - G * T_B         # 1819.64 m/s


def test_matches_closed_form():
    v = integrate(vacuum_burn, 0.0, np.array([0.0]), T_B, 40)   # h = 0.5 s
    assert v[0] == pytest.approx(V_B, rel=1e-7)


def test_fourth_order_convergence():
    e1 = abs(integrate(vacuum_burn, 0.0, np.array([0.0]), T_B, 20)[0] - V_B)
    e2 = abs(integrate(vacuum_burn, 0.0, np.array([0.0]), T_B, 40)[0] - V_B)
    assert e1 / e2 == pytest.approx(16.0, rel=0.1)


def test_free_fall_limit_is_exact():
    f = lambda t, y: vacuum_burn(t, y, mdot=0.0)
    v = integrate(f, 0.0, np.array([10.0]), 3.0, 3)
    assert v[0] == pytest.approx(10.0 - G * 3.0, abs=1e-12)
```

All three tests pass. With h = 2, 1, 0.5 and 0.25 s the errors in v(t_b) are 2.2 × 10⁻³, 1.4 × 10⁻⁴, 8.8 × 10⁻⁶ and 5.5 × 10⁻⁷ m/s: ratios 15.8, 16.0 and 16.0, as fourth order predicts (Euler with the same steps is off by 96, 49, 25 and 12 m/s, halving with h). The free-fall case is exact because the right-hand side is constant, so every Runge–Kutta stage returns the same slope and the step reduces to y + h f. Why a convergence order and a closed form rather than a hard-coded number: the order is the *property* that distinguishes RK4 from a cheaper method that happens to be close at one step size, and the closed form is independent of the implementation, so both tests stay valid if the step, the rocket or the test author's rounding change, whereas a hard-coded value would only re-test the number it was copied from. `solve_ivp` is still the production choice because it controls the error adaptively (changing the step where the right-hand side changes fast, as near burnout here), handles events such as m → m_dry, and has been tested on far more problems than one exam. *Proficient:* a correct four-stage step with the 1-2-2-1 weights, the three tests present and passing, the explanation of the two test styles, and the adaptive-step reason for `solve_ivp`.
