# P10.04  Hints

One hint per problem. A hint points at the idea, not the answer. Read `method.md` next if the hint is not enough.

1. 1 − 2x = cos θ when x = (1 − cos θ)/2. A slope equal to 4h cos θ has only one Fourier cosine term.
2. (a) Substitute term by term; the A₀ term needs the n = 0 and n = 1 Glauert integrals. (b) ∫₀^π (1 + cos θ) dθ = π and ∫₀^π sin nθ sin θ dθ = (π/2) δ_n1. (c) Set c_l = 0 and solve for α. (d) The slope is −δ behind the hinge, zero ahead; integrate cos nθ from θ_h to π.
3. The tab and the camber superpose, so the tab's moment must cancel −0.0531. Trailing-edge up is a negative δ.
4. Every Fourier coefficient is linear in the camber slope, which is linear in m.
5. On a uniform grid with n a multiple of 5, x = 0.4 is always a panel edge; on cosine spacing it almost never is.
6. Ask what happens to the flow at the hinge when the flap is deflected 30°, and whether the slope of the camber line is still "small".
